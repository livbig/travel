# travel — «Фанаты путешествуют»

Статическая страница-карта: 19 городов в пределах одного бака от Подольска. Выбор города →
маршрут на карте, расстояние, время, топливо, платные участки, что посмотреть / где поесть / бары.

- Прод: **https://livbig.github.io/travel/** (GitHub Pages, ветка `main`).
- Репозиторий публичный: `https://github.com/livbig/travel`.
- Сборки нет: что в `main`, то и опубликовано.
