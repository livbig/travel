## 4. Проверка «готово»

Автотестов нет. Изменение считается проверенным, если:

- страница открылась локально (`python3 -m http.server 8099`);
- клик по городу открывает панель и рисует маршрут;
- на узком экране (≤ 560 px) нижняя панель не перекрывает карту целиком;
- в консоли браузера нет ошибок;
- после пуша — проверено на `https://livbig.github.io/travel/`.

20.10.2026 в рамках уборки проверен только HTTP-ответ прода; интерактив не прогонялся.

## 5. Риски и правила

- Репозиторий публичный: секретов, ключей и личных данных здесь быть не должно.
- `routes.js` перезаписывается `fetch_routes.py`; ручные правки потеряются.
- `fetch_routes.py` в `.gitignore`: генератор существует только локально.
- Расстояния, время и сборы ориентировочные; дисклеймер в панели сохранять.
- Формула топлива (`distanceKm × 8 л/100 км × 80 ₽/л`) продублирована в шапке `cities.js`
  и в дисклеймере `app.js` — менять в обоих местах.
