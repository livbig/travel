# AGENTS.md — «Фанаты путешествуют» (карта выходных от Подольска)

Регламент работы. Правила каталога `~/Desktop/ai/AGENTS.md` действуют и здесь; при конфликте
**приоритет у этого файла**. Язык: интерфейс, данные, комментарии, документация — русский.

## 0. Что это

Личный проект (`self/`): одна статическая страница — интерактивная карта 19 городов в пределах
одного бака от Подольска. Выбор города → маршрут на карте, расстояние, время, топливо, платные
участки, что посмотреть / где поесть / бары.

- Репозиторий **публичный**: https://github.com/livbig/travel (ветка `main`).
- Прод — GitHub Pages: https://livbig.github.io/travel/ (`.nojekyll` отключает обработку Jekyll).
- Сборки нет: что лежит в `main`, то и публикуется.
- Состояние на сейчас — [`docs/PROJECT-STATE.md`](docs/PROJECT-STATE.md).

## 1. Файлы

| Путь | Что |
|---|---|
| `index.html` | разметка; подключает MapLibre GL `5.6.0` (unpkg) и Google Fonts |
| `app.js` | вся логика: карта, маркеры, панель города, анимация маршрута |
| `cities.js` | данные 19 городов (`const CITIES = [...]`); координаты — `[lat, lon]` |
| `routes.js` | **сгенерированный** `window.ROUTES` (геометрия OSRM) — руками не править |
| `style.css` | стили, в т.ч. мобильная нижняя панель |
| `fetch_routes.py` | генератор `routes.js` (публичный OSRM demo API); **не в git** (`.gitignore`) |

## 2. Команды

```bash
cd ~/Desktop/ai/self/travel
python3 -m http.server 8099     # локальный просмотр: http://127.0.0.1:8099/
python3 fetch_routes.py         # пересобрать routes.js из OSRM (пауза 1 c между запросами)
git add <свои файлы> && git commit && git push   # деплой: Pages публикует main сам
```

## 3. Правила

- **Репозиторий публичный — секретов, ключей и личных данных здесь быть не должно.**
- Расстояние, время и сборы ориентировочные. Дисклеймер в панели (`app.js`, `renderCity`)
  сохранять.
- Стоимость топлива — `distanceKm × 8 л/100 км × 80 ₽/л`. Меняешь формулу — правь её в обоих
  местах: комментарий-шапка `cities.js` и дисклеймер `app.js`.
- `routes.js` генерируется `fetch_routes.py`; править руками нельзя — перезапишется.
- `fetch_routes.py` в `.gitignore`: генератор существует только локально, в репозитории его нет.
- Внешние зависимости зафиксированы: MapLibre GL `5.6.0`, базовые тайлы CartoCDN dark-matter,
  шрифты Google. Новые CDN/библиотеки — только по прямой просьбе.
- Координаты в `cities.js` — `[lat, lon]`; `app.js` разворачивает их в `[lon, lat]` для MapLibre.
  Формат городов в `fetch_routes.py` — `(lon, lat)`.

## 4. Проверка «готово»

Автотестов нет. Изменение проверено, если: страница открылась локально (`python3 -m http.server`),
клик по городу открывает панель и рисует маршрут, на узком экране (≤ 560 px) нижняя панель не
перекрывает карту целиком, в консоли браузера нет ошибок. После пуша — проверить
https://livbig.github.io/travel/.

## 5. Чего не делать

- Не коммитить `fetch_routes.py` (он в `.gitignore`) и вообще ничего из личных путей.
- Не пушить без прямой просьбы (правило корня §6); пуш = публикация, поэтому только по запросу.
- Не переписывать `cities.js` «на глаз»: расстояния и платные участки сверять перед правкой.
